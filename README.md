# Cyberpunk-3: Засада на UNL-2

Реализация настольной игры "Киберпанк-3: Засада на UNL-2" на C# в рамках изучения ООП.

## Описание проекта

Этот проект создан для методички по объектно-ориентированному программированию.
Пошаговая разработка игры демонстрирует применение принципов ООП, SOLID и паттернов проектирования.

## Текущий статус

Глава 1: Базовые классы `Goblin` и `Cyborg`
- Поля и свойства
- Методы стрельбы и движения
- Конструкторы

## Технологии

- C# 10
- .NET 10.0
- Console Application
